# Together WorX website

Static site for togetherworx.org. Netlify publishes the repository root on every push to `main`.

- Pages are generated by `_src/build.py`. Edit copy there, then run `python3 _src/build.py` from the repo root.
- Shared styles: `assets/site.css`. Scripts: `assets/site.js`.
- Images: `assets/img/` (web-sized, color-graded). Videos: `assets/video/`.
- Forms (`contact`, `updates`) are handled by Netlify Forms.
